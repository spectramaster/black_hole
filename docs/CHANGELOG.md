### 🔬 Kerr 黑洞物理（旋转黑洞）

**新物理效果**:
- ✨ **惯性系拖曳** (Frame Dragging / Lense-Thirring Effect)
  - 时空被旋转黑洞拖动
  - 角动量 ω = 2Mra/(ρ² + 2Mra²sin²θ)

- 🌀 **能层** (Ergosphere)
  - r_ergo = M + √(M² - a²cos²θ)
  - 紫色光晕可视化
  - 允许能量提取 (Penrose 过程)

- 🔵 **自旋相关 ISCO**
  - 顺行轨道: r_isco ≈ M(3 + Z₂ - √((3-Z₁)(3+Z₁+2Z₂)))
  - a = 0.998 时，ISCO 可达 1.23M（极限情况）
  - 逆行轨道: r_isco 更大

- 💫 **增强的吸积盘效果**
  - 差动旋转速度随自旋参数变化
  - 内圈转速更快（靠近极限光速）
  - 更强的多普勒效应

### ⚡ 性能优化系统

**自适应质量管理**:
- 实时监控平均 FPS (60 帧滑动窗口)
- FPS < 目标 85% → 30 帧后自动降低质量
- FPS > 目标 105% → 120 帧后自动提升质量
- 平滑过渡，避免突然卡顿

**质量等级**:
```
LOW:    640x480   @ 30k steps  (60+ FPS, 低端 GPU)
MEDIUM: 800x600   @ 60k steps  (45-60 FPS, 中端 GPU)
HIGH:   1280x720  @ 80k steps  (40-60 FPS, 高端 GPU)
ULTRA:  1920x1080 @ 120k steps (30-45 FPS, 旗舰 GPU)
```

**性能统计**:
- 当前/平均/最小/最大 FPS
- 帧时间分析
- 自动性能日志（每 60 帧）
