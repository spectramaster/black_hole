### 1. 双黑洞合并动画系统 ⭐ 优先级最高

**目标**: 实现物理精确的双黑洞轨道演化和合并过程

**技术要点**:
- 后牛顿近似 (Post-Newtonian Approximation)
- 轨道动力学方程
- 引力辐射能量损失
- 合并时间计算
- 轨迹插值和平滑

**文件结构**:
```
src/physics/
  ├── binary_black_hole.h       (已创建)
  ├── binary_black_hole.cpp     (已创建)
  └── orbit_dynamics.h          (待创建)

shaders/
  └── binary_merger.comp        (待创建)
```

**实现步骤**:
1. 实现 BinaryBlackHole 类
   - 轨道参数 (半长轴 a, 偏心率 e, 倾角 i)
   - 质量比 q = M2/M1
   - 轨道演化方程
   
2. 引力波辐射
   - 能量损失率: dE/dt = -(32/5) G⁴/c⁵ (M1 M2)²(M1+M2)/a⁵
   - 轨道衰减
   - 合并时间估计

3. 动画系统
   - 关键帧生成
   - 轨道插值
   - 碰撞检测
   - 最终合并效果

**测试**:
- 轨道稳定性测试
- 能量守恒验证
- 合并时间精度测试
