### 🍎 2. macOS 完全兼容
**问题**: 原代码仅支持 Windows (OpenGL 4.3)
**解决**:

```cpp
#ifdef __APPLE__
    // macOS: OpenGL 4.1 Core Profile
    glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 4);
    glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 1);
    glfwWindowHint(GLFW_OPENGL_FORWARD_COMPAT, GL_TRUE);
#else
    // Linux/Windows: OpenGL 4.3
    glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 4);
    glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
#endif
```

### 🌌 3. 惊艳的吸积盘渲染引擎

#### 实现的物理效果：

**① Shakura-Sunyaev 温度模型**
```
T(r) ∝ (M/r³)^(1/4)
```
- 内边界 (ISCO): ~10⁷ K 蓝白色 💎
- 外边界: ~10⁴ K 深红色 🔥
- 平滑温度梯度

**② 多普勒红移/蓝移** 🔵🔴
```
δ = 1 / [γ(1 - β·cos(θ))]
```
- 前侧（朝向观察者）: 蓝移 + 变亮
- 后侧（远离观察者）: 红移 + 变暗
- 清晰的颜色不对称

**③ 引力红移**
```
z_grav = 1/√(1 - r_s/r) - 1
```
- 深引力势阱中的光子能量损失
- 越靠近黑洞，红移越强

**④ 相对论性增亮（Beaming）** ✨
```
I' = δ³ * I
```
- 靠近侧强烈增亮
- 立体感和动态范围大幅提升

**⑤ 黑体辐射颜色映射** 🌈
- 基于 Planck 曲线
- 物理真实的温度-颜色转换
- 从深红到蓝白的完整光谱
